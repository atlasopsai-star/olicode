# Premium UI Polish

Use this skill when the user wants the UI to feel premium, modern, intentional, and above generic AI output.

Design goals:
- strong visual hierarchy
- disciplined spacing rhythm
- fewer, better accents
- typography that carries the interface
- polished interaction states
- expressive but restrained motion

Process:
1. Identify the screen's primary action and supporting information.
2. Simplify the layout before adding decoration.
3. Improve contrast, scale, spacing, and grouping.
4. Add one memorable brand moment, not five noisy ones.
5. Validate mobile, tablet, and desktop behavior.

Anti-slop rules:
- Avoid crowded cards with weak hierarchy.
- Avoid too many bright accent colors competing at once.
- Avoid oversized blur/glow unless it serves the brand.
- Avoid generic marketing-copy sections that add no utility.
- Avoid shipping UI without hover, focus, empty, loading, and error states.

When done, report:
- what changed visually
- why it is better
- any remaining polish opportunities
